# 🎬 Demo GIF Capture Guide

The README embeds 4 clips from this folder. Record them, drop them in with the **exact filenames** below, and they render automatically on GitHub.

## Tool (Windows)
**[ScreenToGif](https://www.screentogif.com/)** — free, records a screen region straight to optimized GIF. (macOS: [Kap](https://getkap.co/). Cross-platform: [LICEcap](https://www.cockos.com/licecap/).)

## Settings
- **Width:** ~1000–1280px · **FPS:** 15 · **Colors:** 256 · **Size target:** < 8 MB each (GitHub caps inline media ~10 MB).
- In ScreenToGif: after recording, **File → Save As → GIF**, enable the built-in optimizer (reduce frame count + transparency).

## Tips for a brutal money shot
- Zoom the camera **in on your hero** before praying so the bolt fills the frame.
- Record at night (day/night cycle) — the blue bolt pops harder on a dark map.
- Trim dead frames at the start/end so the GIF loops tight on the strike.
